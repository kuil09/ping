# 탭 카운트다운

남은 시간은 제목의 맨 앞: `04:59 · ping · 1/3명`. 새 핑은 누구의 핑이든 5분으로 갱신한다. 백그라운드의 미확인 핑은 12초 동안 제한적으로 제목/파비콘을 강조하고 이후 고정한다. 동작 줄이기 설정은 고정 표시한다.

만료 시각과 서버 시간 차이를 사용하므로 타이머가 늦게 실행되어도 누적 오차 없이 복구한다. 숨긴 탭도 실행 가능한 동안 WebSocket을 유지하지만, 모바일 OS가 탭을 정지시킨 상태에서 매초 갱신을 강제하지 않는다. 화면 복귀 시 연결을 복구한다. 카운트다운 때문에 서버 호출하지 않는다.
